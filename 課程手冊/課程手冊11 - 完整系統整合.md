## 第一部分：前置準備

### Step 1：確認 Docker 和 Image

```bash
cd ~/stock-crawler

# 確認 stock-airflow image 存在（手冊08 build 過）
docker images | grep stock-airflow
```

如果沒有，先 build：

```bash
docker build -f airflow/Dockerfile -t stock-airflow:latest .
```

### Step 2：準備 .env

```bash
cp .env.example .env
```

---

## 第二部分：一鍵啟動全部服務

```bash
docker compose -f docker-compose-all.yml up -d
```

這會啟動 11 個容器：

| 容器 | 說明 |
|------|------|
| rabbitmq | 訊息佇列（Broker） |
| flower | Celery 監控 |
| mysql | 業務資料庫 |
| phpmyadmin | MySQL Web 管理 |
| crawler_twse | Celery Worker（上市股票） |
| crawler_tpex | Celery Worker（上櫃股票） |
| airflow-postgres | Airflow metadata DB |
| airflow-init | 初始化（一次性，跑完會 Exit） |
| airflow-webserver | Airflow Web UI |
| airflow-scheduler | Airflow 排程器 |
| metabase | BI 視覺化工具 |

等待約 60-90 秒讓所有服務就緒。

## 第三部分：7 步驟端到端驗證

### Step 1：服務狀態

```bash
docker ps -a --format 'table {{.Names}}\t{{.Status}}' | sort
```

✅ **預期**：全部 Up（`airflow-init` 為 `Exited (0)` 正常）

### Step 2：Web 介面

```bash
curl -s -o /dev/null -w '%{http_code}' http://localhost:15672  # RabbitMQ
curl -s -o /dev/null -w '%{http_code}' http://localhost:5555   # Flower
curl -s -o /dev/null -w '%{http_code}' http://localhost:8080   # phpMyAdmin
curl -s -o /dev/null -w '%{http_code}' http://localhost:8081/health  # Airflow
curl -s -o /dev/null -w '%{http_code}' http://localhost:3000/api/health  # Metabase
```

✅ **預期**：全部 200（Metabase 可能需要多等 30 秒）

### Step 3：Logs 檢查

```bash
docker logs crawler_twse 2>&1 | tail -3   # 看到 "ready"
docker logs crawler_tpex 2>&1 | tail -3   # 看到 "ready"
docker logs airflow-init 2>&1 | tail -3   # 看到 "User admin created"
```

✅ **預期**：Worker ready、Airflow admin 建好、無 error

### Step 4：發任務

```bash
cd ~/stock-crawler
uv run python -m crawler.producer_multi_queue
```

✅ **預期**：`send task_2330 task` + `send task_00679b task`

### Step 5：Worker 執行

```bash
sleep 5
docker logs crawler_twse 2>&1 | grep succeeded | tail -3
docker logs crawler_tpex 2>&1 | grep succeeded | tail -3
```

✅ **預期**：`Task crawler.tasks_crawler_finmind.crawler_finmind succeeded`

### Step 6：DB 驗證

```bash
docker exec mysql mysql -uroot -p1234 mydb -e \
  "SELECT stock_id, COUNT(*) as cnt FROM TaiwanStockPrice GROUP BY stock_id"
```

✅ **預期**：看到 2330 和 00679B 各有數百筆資料

### Step 7：Airflow DAG 驗證

```bash
docker exec airflow-webserver airflow dags list 2>&1 | grep stock
```

✅ **預期**：看到 stock_crawler_dag、stock_crawler_producer_dag 等 DAG

開啟瀏覽器 http://localhost:8081 登入（admin/admin），確認 DAG 列表。

## 第四部分：服務總覽與 Port 對照

| Port | 服務 | URL | 帳密 |
|------|------|-----|------|
| 5672 | RabbitMQ（AMQP） | — | worker / worker |
| 15672 | RabbitMQ 管理介面 | http://localhost:15672 | worker / worker |
| 5555 | Flower | http://localhost:5555 | — |
| 3306 | MySQL | — | root / 1234 |
| 8080 | phpMyAdmin | http://localhost:8080 | root / 1234 |
| 8081 | Airflow | http://localhost:8081 | admin / admin |
| 3000 | Metabase | http://localhost:3000 | 首次設定 |

## 第五部分：常見問題排查

| 問題 | 原因 | 解法 |
|------|------|------|
| Worker log 顯示 Connection refused | RabbitMQ 還沒 ready | Worker 會自動重連，等幾秒即可 |
| Airflow Web UI 打不開 | init 還沒跑完 | `docker logs airflow-init` 確認完成後 `docker restart airflow-webserver` |
| Metabase 503 | JVM 啟動慢 | 等 30-60 秒再試 |
| port 衝突 | 其他程式佔了 port | 先 `docker compose down` 其他 compose，或改 port |
| stock-airflow image 不存在 | 沒 build 過 | `docker build -f airflow/Dockerfile -t stock-airflow:latest .` |
| MySQL table 不存在 | 還沒跑過爬蟲 | 先發任務（Step 4）或載入 mock 資料：`docker exec -i mysql mysql -uroot -p1234 mydb < example/mock_stock_price_data.sql` |

```bash

```

```bash
docker compose -f docker-compose-all.yml down -v
```
